I created an Expense Tracker project using HTML, CSS, and JavaScript. This project helps users to keep track of their income and expenses in a simple way. Users can enter the title, amount, and select whether it is income or expense. After adding the details, the total income, total expense, and remaining balance are updated automatically.

It also shows the transaction history and users can delete any transaction if needed. I designed the project with a clean and responsive interface so it can be used easily on both mobile and desktop devices.

Technologies Used:
HTML
CSS
JavaScript
